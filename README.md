# josiasjuca.github.io

Portfólio pessoal de **Josias Cavalcante** — Analista de Dados (Power BI, SQL, Python).

🔗 **https://josiasjuca.github.io/**

## Stack

HTML, CSS e JavaScript puros — sem frameworks, sem build. Hospedado no GitHub Pages.

- Tema escuro/claro com persistência em `localStorage`
- Efeito de digitação, reveal on scroll e lightbox em vanilla JS
- Responsivo e acessível (skip link, `prefers-reduced-motion`, ARIA)

## Rodando localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```
